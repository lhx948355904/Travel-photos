## 下一轮需要确定的实施条件

1. **实时证据标准**：实时天气是否足以支持“当前适合户外游玩/拍摄”；涉及红叶、花期或开放状态时，是否要求对应景点的专项实时来源。建议按问题类型分别设门槛，缺少对应证据就不形成当前排名。
2. **外部来源选型**：确定 POI、天气和照片的实际提供方；确认账号、Web 服务 Key、流量配额，以及图片是否允许在本页面展示和如何署名。调研结论不是接入授权。
3. **DashScope 额度**：访客场景的单次、单位时间和每日上限，达到上限后的提示；确定实际可用模型和部署地域。
4. **地区时间**：回答显示的当地日期、时区和实时数据发布时间；不同地区不能只按服务器日期判断季节。

以上条件未确定前，文档可以进入技术方案细化，但不得声称“当前推荐”和外部照片接入已具备上线条件。
