# AI 游玩与摄影交流页：逐条可验证结果

状态：验收清单草案。当前只完成代码现状核对与文档编写，下表全部属于后续功能验收，**尚未通过运行测试**。依赖 [05-待确认决策](05-decisions.md) 的条目在确认后补齐测试数据。

| ID | 准备与操作 | 预期结果 | 验证方式 |
| --- | --- | --- | --- |
| AC-01 | 分别从首页和地图页打开独立交流页 | 两处均有入口；交流页可见输入、回答区、列表和地图；`/map` 原页面仍可访问 | 浏览器桌面与手机视口 |
| AC-02 | 提问“逆光拍风景怎么曝光？” | 文字逐步出现并最终完成；不强制显示无依据的地点点位 | 控制网络速度观察流式 UI |
| AC-03 | 提问“现在适合去哪拍秋景？”，给出地区，并提供符合最终标准的实时测试数据 | 回答标明地区、日期、实时数据来源及发布时间；有可靠候选时列表按序显示理由，地图有一一对应点位 | 固定候选、日期与实时数据的端到端测试 |
| AC-04 | 点击列表第 2 项，再点击另一地图点 | 地图聚焦第 2 项；点位点击后列表、照片和理由切换到同一结果 ID | 页面交互测试 |
| AC-05 | 提问“帮我写一段 Java 排序代码” | 委婉说明本页服务范围，不显示推荐点 | 服务端主题判断测试及页面检查 |
| AC-06 | 提问“去哪拍秋景，顺便帮我修复数据库？” | 只回应景色/摄影部分，明确略过无关部分 | 混合问题样例测试 |
| AC-07 | 提问“现在去哪玩”且不提供城市 | 先请用户补充目的地或出发城市；补充前不输出具体地点排名，也不静默采用地图中心或浏览器坐标 | 清空地区设置后手动/自动测试 |
| AC-08 | 候选地点无合法坐标或同名无法确认 | 该地点不落图；展示“位置待确认”或请求澄清 | 伪造无坐标/重名数据测试 |
| AC-09 | 候选地点没有可用照片，或图片加载失败 | 推荐文字和地图仍可用，卡片显示无图/加载失败状态 | 断图与空图片数据测试 |
| AC-10 | 模型返回不存在的地点 ID、照片 ID、越界经纬度或无效字段 | 服务端拒绝或过滤错误结构；前端不显示虚构点/照片 | 服务端契约测试 |
| AC-11 | 回答生成中按停止，然后立即发第二个问题 | 第一轮停止，旧分片不覆盖第二轮文本、列表或地图 | 模拟延迟流与连续提交测试 |
| AC-12 | 模型超时或中途断流 | 显示失败/未完成状态及重试入口；未完成地点列表不当作已核实结果 | 故障注入测试 |
| AC-13 | 地图 SDK 不可用 | 回答与按序列表保留，地图区显示错误状态 | 屏蔽地图资源测试 |
| AC-14 | 请求“今天红叶是否正盛、景点是否开放”，但专项实时资料缺失或过期 | 明确说明无法核实；不生成已验证的“当前秋景/当前开放”排名或确定性承诺 | 固定无实时源和过期数据环境测试 |
| AC-15 | 输入试图指示模型绕过主题/输出规则 | 输出依然受主题与引用校验约束，不泄露服务端密钥或产生未核实地图点 | 提示词注入样例测试 |
| AC-16 | 分别以未登录访客和管理员身份访问、调用 AI 能力 | 两者均可使用；服务端公开限额与错误提示符合最终规则，不依赖前端身份伪装 | 权限集成测试 |
| AC-17 | 在窄屏、键盘操作和图片/地图加载慢的环境使用 | 能完成提问、查看列表、选点、停止/重试；焦点与状态可识别 | 响应式与可访问性检查 |
| AC-18 | 回到现有 `/map`，搜索地点、点击相册点；管理员执行原上传/编辑流程 | 原地图和画廊、搜索、管理行为与改动前一致 | 现有回归检查 |
| AC-19 | 推荐一个不在相册中的外部景点，并返回具展示权的外部照片 | 点位和照片可显示且标明外部来源；照片无授权或失效时展示无图状态 | 外部数据契约与页面测试 |
| AC-20 | 用户只说“从杭州出发，现在去哪玩？” | 先追问愿意去多远；得到距离答复前不输出具体地点排名 | 对话状态测试 |
| AC-21 | 完成一次对话后关闭或刷新交流页 | 不恢复此前聊天记录；后台也不生成对话历史记录 | 页面与数据层检查 |
| AC-22 | 实时来源失败、过期或仅返回天气而问题询问红叶现状 | 不输出缺乏对应证据的“当前适合”排名；提示缺少哪类数据 | 实时来源故障与证据类型测试 |

## 验收记录格式

实现后对每条记录 `通过/失败/未执行`、测试环境、输入数据、截图或测试命令、失败原因。只有 AC-01～AC-22 的适用项均通过，且 [05-决策记录](05-decisions.md) 中影响行为的待定项已关闭，才可称此功能满足首版验收。当前因仅编写文档，不能声称页面或接口已实现。
