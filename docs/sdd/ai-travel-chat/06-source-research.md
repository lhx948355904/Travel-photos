# 外部景点、实时信息与照片来源调研

调研日期：2026-10-12。此文是候选方案调研，**不表示接口已开通、已取得图片授权或已选定最终提供方**。与 [05-决策记录](05-decisions.md) 配套。

## 1. 已核对的官方来源

| 候选 | 可用于什么 | 已确认限制与核验点 |
| --- | --- | --- |
| 高德搜索 POI 2.0 | 支持关键字、周边、区域及 ID 检索；可取得 POI 名称、地区、坐标，部分扩展字段含图片和营业时间。适合在现有高德地图内核实候选景点 | 官方注明该服务面向企业开发者试用，上线前需就流量配额咨询；需要 Web 服务类型 Key。营业时间字段不等于实时开放状态，图片字段有链接也不等于允许脱离平台条款使用。[高德 POI 2.0 文档](https://lbs.amap.com/api/webservice/guide/api/newpoisearch) |
| 高德天气查询 | 按地区 `adcode` 获取实况和未来天气，响应带 `reporttime`。可作为“当前天气适不适合户外游玩/拍摄”的一项实时依据 | 需要 Web 服务类型 Key；天气按地区而非景点微地点提供；只证明天气，不证明红叶、花期、景区开放或道路状况。[高德天气文档](https://lbs.amap.com/api/webservice/guide/api/weatherinfo) |
| Wikimedia Commons | 候选外部照片；文件页可查看独立许可和作者信息，API 的扩展元数据可辅助读取署名字段 | 每张照片的许可、作者、署名、改动及地点真实性仍要逐项核验；站点不保证上传许可信息绝对正确。不能只按关键词检索就认定照片拍摄于某景点。[复用指南](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia/en)、[API 署名字段](https://commons.wikimedia.org/wiki/Commons:Credit_line/en) |
| Unsplash API | 提供关键词照片搜索，适合作为景观氛围配图候选 | API 要求图片 URL 直接嵌入、显示 Unsplash 与摄影师署名并链接摄影师页；演示额度和生产额度不同，生产需申请。关键词匹配不证明图中就是推荐景点，若无法核实地点，只能标“示意图”，不能当景点实拍。[API 文档](https://unsplash.com/documentation)、[API 条款](https://unsplash.com/api-terms) |
| DashScope | 用户已指定的大模型服务；官方支持流式输出 | 需服务端持有 API Key，并核对实际模型、地域、调用额度；模型的流式能力不能代替景点、照片和实时数据核验。[阿里云流式输出文档](https://help.aliyun.com/zh/model-studio/stream) |

## 2. 许可与数据使用边界

- 高德官方服务协议对相关内容的存储、缓存、抓取、脱离服务单独展示等有明确限制。高德 POI 文档虽然列出 `photos` 字段，也不能据此断定这些照片可以保存到本站 COS、长期缓存、交给模型二次处理或在独立画廊展示；需要按实际使用方式核对协议，必要时向平台确认。[高德开放平台服务协议](https://lbs.amap.com/pages/terms/)
- Wikimedia Commons 的文件有各自许可证；若要求署名或相同方式共享，需要在具体卡片上履行。图片版权状态与景点身份也需要独立核验。[Wikimedia Commons 复用指南](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia/en)
- Unsplash 一般图片许可与 **API 条款**不同：通过 API 展示时，条款要求平台与摄影师署名、摄影师主页链接、直接使用所给图片 URL。若采用它，还需检查应用场景与图片地理真实性。[Unsplash API 条款](https://unsplash.com/api-terms)、[API 文档](https://unsplash.com/documentation)

## 3. 对“当前推荐”的能力判断

高德天气的 `reporttime` 可以给天气证据设新鲜度条件。高德 POI 2.0 的 `opentime_today` 是当日营业时间字段，不能替代当日临时闭园公告。调研到的这些通用接口没有提供可覆盖全国景点的即时红叶、花期或现场景色证据。因此：

1. 只拿到实时天气时，可说“按当前天气和通常季节特征，这些地点适合考虑”，同时明确“红叶/花期未核实”；是否将这类回答称为“当前推荐”还需产品确认。
2. 用户若问“今天红叶是否正盛/景点现在是否开放”，需要能核验该景点的专项实时来源；缺失时不输出确定性结论，也不把排名包装成已验证的当前秋景榜。
3. 实时来源不可用、过期或覆盖不到指定地区时，不能继续生成带“当前适合”含义的地点排名；可提示重试或改问非实时的一般游玩/摄影知识。

以上第 1 点属于基于已查资料的**产品推断**，不是接口本身保证。

## 4. 下一步选型建议，尚未授权实施

| 顺序 | 建议验证事项 | 通过条件 |
| --- | --- | --- |
| 1 | 核对现有高德账号是否具备 Web 服务 Key、POI 2.0 上线资格和天气额度 | 账号、Key 类型、额度、地域和实际响应字段均可核验 |
| 2 | 在实际目标地区选 3～5 个景点验证 POI 坐标、重名处理与天气地区编码 | 不错点；源数据含明确更新时间；有异常可降级 |
| 3 | 优先试验能逐张核实景点身份和许可的 Wikimedia Commons 照片；不足时再评估 Unsplash 或高德照片授权 | 每张图有原始页、作者、许可、署名方式及“真实景点/示意图”标识 |
| 4 | 选定哪些实时信号足以支持“当前适合”，并设过期时间和失败行为 | 无实时信号时不会形成当前推荐；天气不会被误写成花期/开放证明 |

上述顺序是工程建议，不是替你决定供应商。正式接入前需确认 [05-决策记录](05-decisions.md) 里剩余的额度与实时证据标准。
