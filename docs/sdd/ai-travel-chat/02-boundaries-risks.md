# AI 游玩与摄影交流页：边界、问题与解决策略

状态：需求风险分析；与 [01-具体需求](01-requirements.md) 和 [05-待确认决策](05-decisions.md) 配套。

| 编号 | 边界或可能问题 | 解决策略 | 可观察结果 |
| --- | --- | --- | --- |
| B-01 | “景色、游玩、摄影”与无关话题边界模糊；模型可能被“忽略规则”等文本诱导 | 服务端做主题判定与输出约束；混合问题只答相关部分；超范围统一委婉回绝 | 无关问题没有推荐点；混合问题仅出现相关内容 |
| B-02 | 模型编造景点、经纬度、照片、开放信息或季节事实 | 候选地点及坐标以数据源核验；照片引用需能映射到真实资源；未经核验内容不进入结构化结果 | 地图无虚构点，照片可追溯，未知信息明确说明 |
| B-03 | 用户说“现在”但没有城市、出发地或目的地 | 先请用户补充目的地或出发城市；仅给出出发城市时再追问愿意去多远。不默认使用浏览器定位、地图当前中心或服务器所在地 | 范围明确前不输出具体地点排名 |
| B-04 | 同一日期不同纬度季节不同；“秋景”不等于当前当地景况 | 当前推荐必须有符合标准的实时依据及发布时间；天气无法证明红叶/花期，缺少专项数据时不作现场景色判断 | 不把一般季节经验包装成当前秋景或当日开放结论 |
| B-05 | 现有 `travelDate`、`shotDate` 是历史日期，不能代表现在 | 仅将其用作本站照片/行程记录，不用作当前景色证明 | 历史照片有来源或拍摄日期说明 |
| B-06 | 站点相册只覆盖作者去过且有可用照片的地点，可能找不到合适结果 | 按确认的数据范围返回真实的少量结果或“暂无可核实推荐”；不为凑数编造候选 | 结果数可为零，空态可理解 |
| B-07 | 已确认允许外部景点及有授权的外部照片，但尚无提供方、许可、来源和失效契约 | 接入前确定外部数据/照片来源；只展示有展示权的照片并标来源；失败时降级为无图地点 | 每张图能识别来源，图失效不影响地图和文字 |
| B-08 | 高德输入提示有重名、无坐标、跨地区同名问题 | 用地点 ID、城市/行政区和检索结果核对；无法消歧时请求用户补充 | 不把错误的同名景点画到地图 |
| B-09 | 文字流可能中途断开，或旧轮次晚到影响新一轮 | 为每轮请求标识状态；取消后忽略迟到分片；仅接收完整校验后的结构化结果 | 停止、重试、连续提问时地图与列表一致 |
| B-10 | 当前 Axios 封装使用一次性 JSON `ApiResponse`，不直接处理逐字流 | 实现阶段单独设计流协议和错误事件，再适配前端读取；不擅自复用普通 JSON 解析流程 | 流式正文可渐进显示，失败信息可被识别 |
| B-11 | 现有地图点代表相册照片，搜索点可触发管理员选点 | 新页用独立的推荐点状态及交互；不通过既有“添加地点”回调展示推荐 | 点击推荐点不会打开上传或改动相册 |
| B-12 | 访客和管理员都可调用 AI，公开使用可能产生成本和滥用 | 服务端允许未登录使用，并定义限流、请求长度、超时、调用预算与异常提示；密钥仅在服务端。具体额度仍待确认 | 未登录访客能使用；超额有明确提示 |
| B-13 | 模型产出的推荐理由可能是广告式或无依据的排名 | 排名采用明确的候选集与可解释因素；标注“推荐顺序”而非客观最优；理由与地点一一对应 | 列表顺序稳定且每项有理由 |
| B-14 | 地图 SDK、图片服务、模型服务、实时来源各自可能不可用 | 分层降级：地图失败保留列表，图片失败保留地点，模型失败给重试；实时来源失败则停止“当前适合”排名，允许改问非实时知识 | 故障时不把空白页或过期数据当成功 |
| B-15 | 在手机屏幕上同时显示对话、地图、排序列表会拥挤 | 在实现设计中保证各区可切换或顺序查看，列表项与点有明显选中态和键盘操作 | 移动端能完成提问、查看排序、定位及返回对话 |

## 必须守住的数据边界

1. `/api/locations` 返回的地点数据只来自站点相册，且当前服务层会过滤没有可用照片的地点；它不是景点目录或实时季节数据源。
2. `.env.example` 中的 `AI_*` 和 `DASHSCOPE_*` 字段，以及 `AI_PRODUCT_ROADMAP.md` 的 RAG 方案，不能证明服务已经接通。实现前需确认供应商、密钥配置和实际部署能力。
3. 不从模型自然语言里解析经纬度直接落图，不将生成文本当作照片元数据或真实旅行经历写入现有表。
4. 推荐、回答和图片都要区分“本站真实记录”“外部来源”“AI 生成解释”，避免用户把推测当成现场事实。
5. 高德 POI 照片字段和实时天气字段的存在，不代表已获存储/展示许可，也不代表可核实时下红叶或开园。候选方案及官方来源见 [外部与实时数据调研](06-source-research.md)。
